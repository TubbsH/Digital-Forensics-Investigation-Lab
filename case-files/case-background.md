# Case Background

**Case ID:** DFI-2026-001  
**Case Type:** Suspected Unauthorized Data Copy  
**Examiner:** Portfolio Demonstration  
**Evidence Type:** Synthetic Windows workstation artifacts

## Allegation

A fictional organization reported that employee Jordan Blake may have copied confidential project files to removable media shortly before leaving the organization.

The investigation is designed to answer the following questions:

1. Was removable media connected to the workstation during the relevant period?
2. Were confidential project files accessed around the same time?
3. Are there artifacts consistent with files being copied?
4. What sequence of events can be reconstructed from the available evidence?

## Scope

This portfolio lab analyzes synthetic browser history, removable-media events, and file activity. The project does not claim to establish criminal intent. Its purpose is to demonstrate forensic methodology, artifact correlation, and careful reporting.
